# Wobjoy — Browser Games

Wobjoy offers free browser puzzles and casual games in English and Chinese.

[Explore Wobjoy](https://wobjoy.com/) · [中文网站](https://wobjoy.com/zh/)

## Egg Bonk
Choose an egg, allocate lucky stickers and challenge nine opponents.
[Play Egg Bonk](https://wobjoy.com/games/egg-bonk/)

## More puzzles
- [Sokoban](https://wobjoy.com/games/sokoban/): push every box onto a goal.
- [Tower of Hanoi](https://wobjoy.com/games/tower-of-hanoi/): move rings between three pegs without placing a larger ring on a smaller one.
- [Shikaku](https://wobjoy.com/games/shikaku/): divide the grid into rectangles using numbered clues.

## Development
Built with Astro, TypeScript, React integration and Cloudflare Workers. Game rules are separate from account and leaderboard features. This repository contains introductions, not production source code or game assets.

[Public game directory on GitHub](https://github.com/inkwen-dev/wobjoy)
