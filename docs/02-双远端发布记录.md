## 二、操作与验证范围

1. 第二个 Chrome 账号为 inkwen-dev；用户在 GitLab 生成 Token 后提供给本机 Git 使用。浏览器会话与 Git HTTPS 凭证分开配置，不再通过 Web IDE 逐文件上传。
2. 首份 Token 认证失败；替换为用户新提供的 Token 后，Git Credential Manager 认证与推送成功。加密凭证及有效状态唯一维护在个人库“账号和密码/平台登录/网站推广账号与凭证索引.md”。
3. 运行 git push gitlab main，并以 git ls-remote gitlab refs/heads/main 核对远端提交。后续记录更新分别推送两个远端，最终提交以两者实际返回为准。
4. 本地生成与相对链接检查曾通过；此前38个主站页面及图片请求均403，未据此宣称线上图片和试玩验证通过。新增语言仍需完整翻译及渲染文案。
